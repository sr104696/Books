# Interview Control Kit

## Purpose
A condensed working kit for turning a resume and a job description into a clear interview narrative—especially when the match is imperfect. It preserves the useful recurring ideas in the source books: evidence over adjectives, concise story-led self-promotion, transferable skills, employer-centered research, and questions that expose what matters. It deliberately excludes motivational material, outdated job-search mechanics, and long lists of canned questions.

## Use in order
1. Read the job description and identify the **three outcomes/problems** the hire must own.
2. Complete `05-STORY-BANK-TEMPLATE.md`; use work, school, volunteer, side-project, or life evidence honestly.
3. Build a 60-second opening with `01-PITCH-60-SEC-FRAMEWORK.md`.
4. Select and repeat the three messages in `02-THREE-PILLARS.md`.
5. Use `03-UNIVERSAL-ANSWER-SUPERSTRUCTURES.md` for live answers; use `06-CONTROL-BRIDGING-TACTICS.md` to clarify or redirect.
6. Rehearse from `08-ONE-PAGER.md`, then paste your materials into `07-LLM-MASTER-PROMPT.md` for tailoring.

## Operating principle
Do **not** pretend to have experience you lack. Translate adjacent evidence into the capability needed: **similar problem → action you took → measurable/observable result → how you will learn the domain and apply the capability here**. A gap becomes credible only when paired with relevant proof and a practical ramp plan.

## Source treatment
Synthesized and paraphrased from the readable interview, self-promotion, question, and job-search EPUBs in this repository, including *101 Great Answers*, *Interview Intervention*, *Get That Job*, *301 Best Questions*, *Brag!*, and *What Color Is Your Parachute?*. Two zero-byte source files could not be reviewed. No source files were altered.
